### Funktionsweise des Facebook-Filters

{{< figure title="Auswahl von Informationen in sozialen Netzwerken" src="filtering.png" attr="[Quelle]" attrlink="/bibliography/#funktionalität-1" width="300" >}}

{{% expand "Potenzielle Informationen des eigenen Netzwerkes" %}}
{{% hint %}}
*Die Auswahl der Nachrichten sind schon von vorne herein begrenzt*, da die angezeigten Nachrichten hauptsächlich von Kontakten geteilt wurden. Das heißt, dass Nachrichten ausserhalb des sozialen Kreises ausgeschlossen werden.
{{% /hint %}}
{{% /expand %}}
{{% expand "Dargestellte Informationen" %}}
{{% hint %}}
*Ein weiterer Bruchteil der verfügbaren Information wird angezeigt*, da Algorithmen  die angezeigten Informationen in der Timeline einer Person automatisch auswählen und sortieren. Die als besonders wichtig eingestuften Inhalte werden vom Algorithmus ganz oben positioniert.
{{% /hint %}}
{{% /expand %}}
{{% expand "Ausgewählte Information" %}}
{{% hint %}}
*Nutzerinnen und Nutzer wählen und betrachten gefilterte Beiträge.* Die Wahrscheinlichkeit, dass eine Nachricht Beachtung findet, sinkt immer mehr, je weiter nach unten gescrollt werden muss.
{{% /hint %}}
{{% /expand %}}
