{{< notice note >}}

Jede Form von Interaktion mit dem System, sei es ein Klick auf ein Produkt, ein Artikel, eine Bewertung (gut oder schlecht) oder ein Like (oder kein Like) erzeugt einen **Feedback** und somit einen neuen [*Kontext*]({{< ref "/recommender-systems/functionality/setup/#kontext" >}}) mit neuen Empfehlungen. Durch eine erneute Interaktion gelangt man dann in eine **Feedback-Schleife**
